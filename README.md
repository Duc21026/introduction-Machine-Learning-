# introduction-Machine-Learning

Quy trình học Machine Learning từ nền tảng đến triển khai, dành cho sinh viên Khoa học Dữ liệu.

## Cấu trúc dự án

```
introduction-Machine-Learning-/
├── lessons/            # Bài học theo chủ đề
├── data/
│   ├── raw/            # Dữ liệu gốc
│   └── processed/      # Dữ liệu đã xử lý
├── notebooks/          # EDA và thử nghiệm
├── src/                # Mã nguồn (data, features, train, predict)
├── models/             # Mô hình đã lưu
├── reports/            # Biểu đồ, báo cáo
├── requirements.txt
└── quy_trinh_hoc_machine_learning.md
```

## Bắt đầu

```bash
python -m venv ml_env
source ml_env/bin/activate
pip install -r requirements.txt
```

## Nội dung

Xem `quy_trinh_hoc_machine_learning.md` để biết lộ trình chi tiết, code mẫu và checklist.
